# 会话标签里运行插件

插件的三种运行位置里，**会话标签**最不一样：它不是弹出层，而是和对话、图片、文档并列的一枚标签。

## 怎么打开

会话顶部标签条右侧的 `+` → 菜单底部「插件」分组 → 选一个已安装的 UI 插件。

- 同一个插件在一个会话里**只开一枚**标签（再点只切过去）；
- 标签关掉 = 插件页面销毁；切走只是摘掉视图，切回来还在原状态（不含滚动位置丢失）。

## 生命周期（插件视角）

```
挂载 → attach（首次创建页面 / 再次进入只重挂）
切走 → hide（页面保活，webContents 不销毁）
关标签 → close（销毁页面）
```

插件页不需要为标签做任何改造：它就是一个普通的 `WebContentsView`，
只是被摆到了标签位置。

## 面板尺寸

标签里的可视区域会随侧栏折叠、右栏开关、窗口缩放变化，dida 会自动同步尺寸；
插件侧只需用相对单位（`height: 100%`）布局，不要写死像素高度。

## 已知边界

- 原生视图永远盖在渲染层之上：标签被切走时 dida 会把它摘下来，但**页面内的弹窗**若被宿主遮挡，属于这条边界；
- 新会话（还没有会话实体）时标签条不产生标签，插件入口在插件页与呼出框仍然可用。
